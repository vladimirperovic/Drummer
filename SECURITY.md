# Security

Drummer processes imported files in the browser and has no login or hosted database. Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/vladimirperovic/Drummer/security/advisories/new), when available. If unavailable, open an issue asking for a private reporting channel without including an exploit or private data.

Include the affected version/commit, browser, reproduction steps and the impact. Do not attach personal sessions, credentials or copyrighted material without permission. The current `main` branch is the supported version; this community project has no guaranteed response time.

The development server is bound to loopback. Public hosting contains only the files included by `alati/build-pages.mjs`.
